# @ri/viz — Agent 2

Pure visualization components with no data fetching or routing. Props are the response types from `@ri/api-contracts`; both Explore concepts receive the same generated Explore fixtures.

- `ExploreTerritories` — deterministic d3 squarified treemap.
- `ExploreStackMatrix` — the stack-first Explore challenger.
- `RobotMRI` — stack view with layer focus and cross-embodiment comparison.

Run `pnpm --filter @ri/viz dev` to review all three against generated fixtures.
